# Class_schedule · 课表

自己用的课程表 Web 应用：**展示当周课表**，并按自己设定的规则**提醒上课**。

> 当前状态：**只完成了设计文档，代码还没开始写。**
> 本 README 描述的是接下来要做成什么样，以及怎么把环境跑起来。

---

## 一、目标

- 一个能在**电脑 / 平板 / 手机**上看的课表网页，不同分辨率都能正常显示
- 能自己定义「什么时候、提醒我什么」，到点电脑弹通知

## 二、技术选型

| 项目 | 选择 | 说明 |
| --- | --- | --- |
| 后端 | Python 3 + Flask | 语言首选 Python；Flask 轻量、够用 |
| 数据库 | SQLite | 单个文件，不用装数据库服务 |
| 前端 | 原生 HTML / CSS / JavaScript | 不引入前端框架 |
| 虚拟环境 | 项目内 `venv` | 项目必须自带虚拟环境 |
| 访问方式 | 局域网 | 电脑上跑服务，手机连同一个 WiFi，用电脑 IP 打开 |
| 提醒 | 后台常驻程序 + Windows 系统通知 | 见 `docs/04-提醒规则.md` |

## 四、环境准备

```bash
cd H:\Projects\Class_schedule

# 1. 建虚拟环境（项目必须自带）
python -m venv venv

# 2. 激活（Windows）
venv\Scripts\activate

# 3. 装依赖
pip install -r requirements.txt
```

## 五、启动

```bash
# 启动网页服务
python app.py

# 另开一个窗口，启动常驻的提醒程序
python notifier.py
```

启动行为（托盘、开机自启等）用命令行参数控制，见 `docs/04-提醒规则.md`。

手机访问：电脑和手机连同一个 WiFi，在手机浏览器打开

```
http://<电脑的局域网IP>:5000
```

电脑 IP 可以用 `ipconfig` 查（找 `IPv4 地址`，一般是 `192.168.x.x`）。
