# 03 · 数据模型

> 数据库用 **SQLite**，文件放在 `../data/class_schedule.db`。
> 网页（Flask）和提醒程序（notifier）读写 **同一个文件**。

---

## 一、表总览

| 表 | 存什么 | 对应页面 |
| --- | --- | --- |
| `semesters` | 学期 | 设置 → 学期 |
| `courses` | 课程 | 课程设置页 |
| `reminders` | 提醒规则 | 设置 → 提醒 |

三张表之外没有别的业务表；「第 x 周」「冲突」这类都是**算出来的**，不另存。

---

## 二、semesters（学期）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER PK | 自增主键 |
| `seq_no` | INTEGER | 学期序号（第几学期），**手动填写**，不自动 +1 |
| `start_date` | TEXT | 起始日期，`YYYY-MM-DD`（页面显示 `yyyy/mm/dd`） |
| `end_date` | TEXT | 结束日期，`YYYY-MM-DD` |
| `is_default` | INTEGER | 1 = 默认学期，**全表最多一个为 1** |
| `created_at` | TEXT | 创建时间 |

### 派生的东西（不存库，每次算）

| 名称 | 算法 |
| --- | --- |
| 第一周的周一 | `start_date` 所在周的周一（**一周以周一开始**；起始日是周日时，该周的周一 = 起始日 - 6 天） |
| 第 x 周 | `(今天 - 第一周的周一) // 7 + 1` |
| 总周数 | `(end_date 所在周的周一 - 第一周的周一) // 7 + 1` |

> 例：学期从 2026/09/01（周二）开始 → 第一周的周一 = 2026/08/31。
> 2026/10/15（周四）时，(10/15 - 08/31) = 45 天，45 // 7 = 6 → 第 **7** 周。

### 规则

- 设置某个学期为默认时：先把所有学期 `is_default` 置 0，再把目标置 1（保证唯一）
- 删除学期时，**连带删除**该学期下的所有课程

---

## 三、courses（课程）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER PK | 自增主键 |
| `semester_id` | INTEGER FK | 属于哪个学期 |
| `name` | TEXT | 课程名称 |
| `teacher` | TEXT | 任课老师 |
| `weekdays` | TEXT | **周几，多选**，存成 `"1,3,5"` 这种（1 = 周一 … 7 = 周日） |
| `start_date` | TEXT | 持续时间起，`YYYY-MM-DD`（填年月日） |
| `end_date` | TEXT | 持续时间止，`YYYY-MM-DD` |
| `start_time` | TEXT | 上课时间，`HH:MM` |
| `end_time` | TEXT | 下课时间，`HH:MM` |
| `location` | TEXT | 上课地点 |
| `color` | TEXT | 颜色，十六进制 `#FFFFFF`（**默认白色**） |
| `note` | TEXT | 备注（**默认空**） |
| `created_at` | TEXT | 创建时间 |

### 新建课程时的默认值

- 年份：自动预填**该学期开始日期所在的年份**
- 颜色：白色 `#FFFFFF`
- 备注：空

### 一件事在「某一天」上不上

```
某门课在日期 D 上课  ⟺
  start_date ≤ D ≤ end_date
  且 D 是周几 ∈ weekdays
```

## 四、reminders（提醒）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER PK | 自增主键 |
| `event` | TEXT | 事件：`new_week` / `new_day` / `class_start` / `class_end` |
| `offset_hours` | INTEGER | 时间差的「时」，0 ~ 23 |
| `offset_minutes` | INTEGER | 时间差的「分」，0 ~ 59 |
| `direction` | TEXT | `before`（前）/ `after`（后） |
| `scope` | TEXT | 提醒范围，见下表 |
| `extra_fields` | TEXT | 附加信息，多选，存成 `"name,location,time"` |
| `enabled` | INTEGER | 1 = 开启，0 = 关闭 |
| `created_at` | TEXT | 创建时间 |

### 枚举值对照

| 界面文字 | 存的值 |
| --- | --- |
| 新的一周到来 | `new_week` |
| 新的一天到来 | `new_day` |
| 每一节课上课 | `class_start` |
| 每一节课下课 | `class_end` |

| 界面文字 | 存的值 |
| --- | --- |
| 下一节课 | `next_class` |
| 今天还没上的课 | `today_remaining` |
| 今天的所有课 | `today_all` |
| 上一节课 | `last_class` |
| 今天上过的课 | `today_done` |
| 明天的课 | `tomorrow` |

| 附加信息（界面文字） | 存的值 |
| --- | --- |
| 名称 | `name` |
| 任课老师 | `teacher` |
| 上下课时间 | `time` |
| 上课地点 | `location` |
| 周几 | `weekdays` |
| 备注 | `note` |

> 附加信息**不含**颜色、起止日期（需求明确）。
> 时间范围 / 日期范围这类「起止日期」不在附加信息里。

## 五、冲突判定

**判定条件（同一学期内）**：两门课的**日期范围有重叠**，并且**某一天的上下课时间段也重叠**。

细化成具体算法：

```
对同一学期里的课程两两比较（A、B）：
  1) 日期范围交集 = [max(A.start_date, B.start_date), min(A.end_date, B.end_date)]
     交集为空 → 不冲突

  2) 在交集范围内，逐天检查：
     该天要同时被 A 和 B 覆盖（日期在各自范围内 且 该天的周几在各自 weekdays 里）
     且 A.start_time < B.end_time 且 B.start_time < A.end_time   ← 时间段重叠
     只要存在这样一天 → A、B 冲突
```

**表现**：

- 课程设置页：冲突的卡片**标红**，提示「⚠ 与《XXX》时间冲突，请修改」
- 课表页：**冲突的两门课都不画**

## 六、课表坐标轴范围（每个学期固定）

需求：同一个学期内坐标轴保持不变，按该学期的课程数据算出合适的值。

```
y 轴（时间）：该学期所有**不冲突**课程里，
              最早的 start_time ~ 最晚的 end_time；
              上下各留一点余量（例如向下取整到整点、向上取整到整点）
              —— y 轴不显示时间刻度文字
x 轴（周几）：**固定 7 列**，周一 ~ 周日，页面下方标出周几

方块定位：
  上边 = 该课 start_time 在 y 范围内的比例
  下边 = 该课 end_time 在 y 范围内的比例
  列   = 该课 weekday
```

> 如果一个学期一门课都没有，就用一个兜底范围（例如 08:00 ~ 22:00）。
