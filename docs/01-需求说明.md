# 01 · 需求说明

> 本文是需求的主文档。凡是讨论中确认过的规则，都写在这里。
> 本文是讨论确认后的最终需求（2026-10-15 全部确认完）。

---

## 一、这是什么

一个自己用的课表网页，外加一个常驻的提醒程序。

- 网页：看当周课表
- 提醒：按自己设的规则，到点弹 Windows 通知

## 二、通用要求

1. 编程语言首选 **Python**，项目必须包含**虚拟环境**
2. 网页要支持**电脑、手机、平板**等设备，支持不同分辨率
3. 总体配色为**白蓝色系**，页面应当**清晰简洁**
   > **2026-10-16 改版**：界面风格改成**淡雅液态玻璃拟态**（半透明玻璃 + 彩色渐变底 + 玻璃质感的课程方块），配色仍以主蓝 `#2F6FED` 为品牌色。详见 [02-界面与交互设计](02-界面与交互设计.md) 第一节。
4. 总体布局：左侧约 **1/5** 是**可以隐藏的菜单栏**，右侧为**内容区**
5. 菜单栏最上方是「课表」页面，下方是「设置」页面；「设置」点开后是**二级菜单**，下面有 **学期** 和 **提醒** 两项
6. 手机上（窄屏）菜单栏默认收起，点 ☰ 从左侧滑出

## 三、学期

**入口：设置 → 学期**

### 3.1 新建学期

- 学期包含：**学期序号**（第几学期）、**起止日期**（yyyy/mm/dd）
- 程序自动查询日历，把**开始当日所在的那一周设为第一周**；**一周以周一开始**
- 创建完成的学期**立即显示在页面中**
- 学期序号**手动填写**，不自动 +1（防止转专业之类的情况）

### 3.2 学期卡片

每个学期以**一个长方形**显示，包含：

| 元素 | 样式 |
| --- | --- |
| 学期序号 | 文字 |
| 设置按钮 | 玻璃白底 + 蓝字 + 蓝边框（描边按钮） |
| 删除按钮 | 红色文字按钮，红色边框 |
| 设为默认 | 蓝色下划线文字按钮，无边框 |

点击某个学期的「设置」之后 → 进入该学期的**课程设置**页面。

点击「删除」→ **先弹一次确认框**（「确定删除这个学期吗？该学期下的课程会一起删除」），确认后才删。

### 3.3 默认学期

- 同时**只能有一个**默认学期；设置新的默认时，自动取消旧的
- 没有任何学期被设为默认时，课表页显示空态（见 5.1 节）

## 四、课程设置页面

- 该页面**不属于菜单栏的任何一个页面**；打开它时，左侧菜单栏**不应有任何一个按钮被点亮**
- 页面顶部展示该学期的**序号**和**起止日期**，方便在这里修改
- 页面中展示一个**课程列表**和一个**添加课程按钮**
- 在此处设置的课程，属性如下：

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| 课程名称 | 文本 | 必填 |
| 任课老师 | 文本 | 必填 |
| 周几 | **多选**（周一 ~ 周日） | 必填 |
| 持续时间 | 从几月几日 到 几月几日，**填年月日** | 新建时自动预填默认年份（与学期开始的年份相同） |
| 上下课时间 | 几点几分 到 几点几分 | 必填 |
| 上课地点 | 文本 | 必填 |
| 颜色 | 可选 | 白色 |
| 备注 | 可选 | 空 |

### 4.1 课程卡片

- 课程创建后**立即显示**在页面中
- 一个课程以一个**长方形卡片**显示，**宽度为网页内容区的 8 分之 7**
- 卡片显示该课程的**所有信息**，其中**颜色通过卡片左侧的有色圆表示**
- 卡片**右侧**显示：

| 按钮 | 样式 |
| --- | --- |
| 设置 | 白色文字按钮，蓝色边框 |
| 删除 | 红色文字按钮，红色边框 |

- 点「删除」→ **先弹一次确认框**（「确定删除这门课吗」），确认后才删

### 4.2 时间冲突

- **冲突的判定**：同一个学期里，两门课的**日期范围有重叠**，并且**某一天的上下课时间段也重叠**
- 冲突的课程在**课程设置页面显示为红色**，用合适的方式提醒用户去修改
- **课表页面不显示时间冲突的课程**

## 五、课表页面

- 网页的**默认页面**，位于菜单栏的**最上方**

### 5.1 没有默认学期时

- 内容区设为**空白**
- 在内容区**中间**绘制「你还没有设置默认学期」字样，以及一个「**前往设置**」按钮

### 5.2 有默认学期时

| 位置 | 内容 |
| --- | --- |
| 内容区左上角 | 「第 x 学期」 |
| 内容区顶部中间 | 「第 x 周」 |
| 内容区右上角 | 「编辑课程」按钮，点击后跳转到该学期的「课程设置」页面 |

### 5.3 课表主体

- 绘制一个类似于屏幕**直角坐标系第四象限**的区域：
  - **y 轴 = 单日的时间**
  - **x 轴 = 周几**
- 在这个坐标系里，根据当周的课程绘制**课程小方块**
- 坐标系的**轴线本身不绘制**（不画箭头、不画格子框）
- **y 轴不标时间刻度**（不写 8:00 / 10:00 这类文字）
- **x 轴下方要标周几**，画 **7 列：周一 ~ 周日**
- 小方块的颜色与课程设置的颜色相同，方块上显示**课程名字**
- 该页面**不可以拖动或缩放**
- 手机竖屏下 7 列**压缩变瘦**，方块里的课程名适当缩短（能看出是哪门课就行）
- 点击小方块 → **弹出**显示该课程的：课程名字、任课老师、上下课时间、上课地点

### 5.4 坐标轴的取值范围

- 同一个学期内，**坐标轴保持不变**
- 取值**依据该学期的课程数据算出一个合适的范围**

### 5.5 第 x 周

- 根据**当前日期**自动计算，第一周 = 学期开始日所在的那一周（周一开始）

### 5.6 不在学期范围内时

- 当前日期**不在**默认学期的起止日期之内（放假）→ 内容区提示「**不在学期范围内**」

## 六、提醒

**入口：设置 → 提醒**

- 页面中展示一个**提醒列表**和一个**添加提醒按钮**
- 一条提醒包含四项设置：**事件、时间差、提醒范围、附加信息（可选）**

### 6.1 事件

- 新的一周到来
- 新的一天到来
- 每一节课上课
- 每一节课下课

### 6.2 时间差

三个下拉框（也可以用滚动条）：

1. **时**（0 ~ 23）
2. **分**（0 ~ 59）
3. **前 / 后**

### 6.3 提醒范围

- 下一节课
- 今天还没上的课
- 今天的所有课
- 上一节课
- 今天上过的课
- 明天的课

### 6.4 附加信息

- 包含**除了颜色以及起止日期以外**所有的课程属性
- **可多选**（例如同时选「名称 + 地点 + 上下课时间」）

### 6.5 示例（原始描述里给的两条）

> 「上课　00：30前　提醒下一节课　名称 地点」
> 「新的一天到来　6：00后　提醒当日所有的课　上课时间 名称」

### 6.6 其他

- 可以有**多个提醒**
- 每条提醒**可以单独开关**（例如周末把「早晨那条」关掉）

### 6.7 提醒怎么送到

- 电脑上挂一个**后台程序常驻**，到点弹 **Windows 系统通知**
- 启动行为**可以在命令行里设置**（托盘、开机自启等，见 04 文档）

## 七、本次约定不做

- 不部署到公网（局域网内部自己用）
- 不引入前端框架（原生 HTML/CSS/JS）
- 不做用户登录 / 账号系统

以下都是讨论中定下来的（2026-10-15 全部确认完）：

| 事项 | 结论 |
| --- | --- |
| 设置按钮的样式 | 玻璃白底 + 蓝字 + 蓝边框（描边按钮） |
| 课表 x 轴 | 画 **7 列**，周一 ~ 周日，页面上标出周几 |
