# 04 · 提醒规则

> 提醒是「电脑上挂一个后台程序常驻，到点弹 Windows 系统通知」。
> 本文把**每一条提醒怎么算**写清楚，实现时照着做。

---

## 一、一条提醒 = 四个零件

| 零件 | 作用 | 选项 |
| --- | --- | --- |
| **事件** | 什么时候（锚点） | 新的一周到来 / 新的一天到来 / 每一节课上课 / 每一节课下课 |
| **时间差** | 相对锚点提前或推迟多久 | 时（0~23）+ 分（0~59）+ 前 / 后 |
| **提醒范围** | 通知里放哪些课 | 下一节课 / 今天还没上的课 / 今天的所有课 / 上一节课 / 今天上过的课 / 明天的课 |
| **附加信息** | 每条课显示什么（可多选） | 名称 / 任课老师 / 上下课时间 / 上课地点 / 周几 / 备注 |

---

## 二、锚点：事件落在什么时刻

| 事件 | 锚点时刻 | 说明 |
| --- | --- | --- |
| 新的一周到来 | **每周一 00:00** | 到这一刻，已经进入新的一周（周一） |
| 新的一天到来 | **每天 00:00** | 到这一刻，进入新的一天 |
| 每一节课上课 | **每节课的 start_time** | 当天有课的每节课各触发一次 |
| 每一节课下课 | **每节课的 end_time** | 当天有课的每节课各触发一次 |

### 触发时刻

```
触发时刻 = 锚点时刻 + (前/后) × (时:分)

「前」= 减    「后」= 加
```

举例：

| 事件 | 时间差 | 触发时刻 |
| --- | --- | --- |
| 新的一天到来 | 6:00 后 | 每天 **06:00** |
| 新的一周到来 | 0:00 后 | 每周一 **00:00** |
| 每一节课上课 | 0:30 前 | 每节课开始前 **30 分钟** |
| 每一节课下课 | 0:10 后 | 每节课下课后 **10 分钟** |

---

## 三、提醒范围：通知里放哪些课

范围都**按触发那一刻动态算**（不是提前算死的）。

| 范围 | 内容 | 举例（现在是 09:50，今天 08:00~09:40 已上完高数，10:00 上 C 语言） |
| --- | --- | --- |
| 下一节课 | **当前时刻及之后最近的一节课**（含正要开始的） | C 语言 |
| 今天还没上的课 | 今天 start_time > 当前时刻的所有课 | C 语言（以及今天更晚的课） |
| 今天的所有课 | 今天全部课，按时间排序 | 高数、C 语言… |
| 上一节课 | **当前时刻及之前最近的一节课**（含刚下课的） | 高数 |
| 今天上过的课 | 今天 end_time ≤ 当前时刻的所有课 | 高数 |
| 明天的课 | **明天**全部课 | 明天有哪些课就列哪些 |

补充规则：

- 只算**今天**（或明天）**真正要上**的课：日期在该课的持续时间内、且那天是它的上课周几
- 课表页**不显示**的冲突课程，提醒里也**不算**（保持一致）
- 范围内**一门课都没有** → **不发通知**（例：周一的「明天的课」= 周二的课；周二没课就不弹）
- 「下一节课 / 上一节课」超过当天范围就当作空（今天的课都上完了 → 没有下一节课）

---

## 四、附加信息：通知正文写什么

选中的字段拼成一条通知，例如：

```
【下一节课】C语言
老师：李老师
时间：10:00 - 11:40
地点：3号教学楼201
```

- 不选附加信息 → 只显示范围标题（例如「下一节课」）
- 附加信息的可选项**不含颜色、不含起止日期**

## 五、完整示例（照原始描述的两条对照）

### 例 1

> 「上课　00：30前　提醒下一节课　名称 地点」

- 事件：每一节课上课
- 时间差：00 时 30 分，前
- 范围：下一节课
- 附加信息：名称、上课地点
- **实际效果**：每节课开始前 30 分钟，弹一条通知，写清「即将上的这节课」的名字和地点

### 例 2

> 「新的一天到来　6：00后　提醒当日所有的课　上课时间 名称」

- 事件：新的一天到来
- 时间差：06 时 00 分，后
- 范围：今天的所有课
- 附加信息：上下课时间、名称
- **实际效果**：每天早上 6:00，弹一条通知，列出今天所有课的时间与名称

### 其他常见组合

| 事件 | 时间差 | 范围 | 效果 |
| --- | --- | --- | --- |
| 新的一周到来 | 0:00 后 | 明天的课 | 每周一凌晨，提醒**周二**要上的课（周一已经开始，所以「明天的课」是周二） |
| 新的一天到来 | 21:00 后 | 明天的课 | 每天晚上 21:00 提醒明天的课（也可以写成『新的一天到来 3:00 前』，效果相同） |
| 每一节课下课 | 0:00 后 | 今天还没上的课 | 每节课下课时，提醒今天接下来还有哪些课 |
| 每一节课上课 | 0:00 前 | 下一节课 | 上课那一刻提醒这节课本身 |

## 六、后台程序（notifier.py）

### 做什么

1. 常驻在后台，每隔一小段时间（例如 30 秒）读一次数据库
2. 算出「从现在起到下一分钟」之间该触发的所有提醒
3. **已经弹过的不重复弹** —— 需要一个「已触发记录」，避免同一时刻反复弹

### 通知形式

Windows 系统通知（右下角气泡），标题 / 正文由「范围 + 附加信息」拼出来。

### 已触发记录怎么存

- 用**简单方案**：内存里记「已触发过的 (提醒id, 触发时刻)」，程序重启就清空（够用）
- 同一时刻如果有**多条提醒**同时命中 → **合并成一条**通知，不要连弹好几条

### 启动方式

**在命令行里设置**（需求明确）。计划提供的参数：

*网页服务（app.py）：*

| 参数 | 作用 |
| --- | --- |
| `--port 5000` | 网页服务端口 |
| `--host 0.0.0.0` | 监听地址（要手机能访问就得是 0.0.0.0） |

*提醒程序（notifier.py）：*

| 参数 | 作用 |
| --- | --- |
| `--tray` / `--no-tray` | 是否缩到右下角托盘 |
| `--autostart` / `--no-autostart` | 是否设置开机自动启动 |
| `--now` | 立刻检查一次并退出（用来测试） |

> 参数名和范围**已定**：暂时就用上面这套（2026-10-15 确认）。

## 七、边界情况

| 情况 | 处理 |
| --- | --- |
| 今天没课 | 「今天的课」类范围为空 → 不发通知 |
| 假期 / 不在学期范围内 | 当天按没课处理（**不提醒**）；课表页提示「不在学期范围内」 |
| 学期还没开始 / 已结束 | 同上，不提醒 |
| 时间差导致触发时刻跨天 | 例如「每一节课上课 3:00 前」，允许跨到前一天；按算出来的绝对时刻触发即可 |
| 同一时刻多条提醒同时命中 | **合并成一条通知** |
| 电脑关机 / 睡眠中 | 不弹（后续可以考虑开机后补一次，本期不做） |
