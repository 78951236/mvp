## 一、配色与风格（淡雅液态玻璃拟态）

> **2026-10-16 改版**：整体风格从原来的「白底 + 蓝点缀、不堆装饰」改成**淡雅液态玻璃拟态**（需求方拍板）。
> 这次改动等于换了风格，原来的「页面底色 `#F7FAFF` / 卡片白 `#FFFFFF` / 边框 `#D8E5FF`」**不再用作面板底色**。

**底色**：页面底部不再是纯白，而是**彩色光晕渐变**（蓝 / 紫 / 青 / 粉四团光晕 + 一层浅蓝渐变打底）。
这是玻璃的前提 —— **玻璃要有东西可透才看得出来**；纯白底上的毛玻璃跟一块浅灰板没区别。

| 用途 | 色值 / 参数 | 说明 |
| --- | --- | --- |
| 主蓝（品牌色） | `#2F6FED` | 主按钮、菜单选中、链接、今天的周几 |
| 主文字 | `#1F2937` | 标题、正文 |
| 次要文字 | `#6B7280` | 说明、次要信息 |
| 警示红 | `#E04545` | 删除按钮、冲突提示 |
| 玻璃面板底 | `rgba(255,255,255,.68)` | 卡片、面板、菜单栏、课表板 |
| 玻璃边缘 | `rgba(255,255,255,.5)` | 面板 1px 亮边 |
| 玻璃高光 | `inset 0 1px 0 rgba(255,255,255,.85)` | 面板顶部那道内亮线 |

**液态玻璃的 4 个旋钮**（都在 `static/css/style.css` 的 `:root` 里，调这 4 个就能改浓淡）：

| 变量 | 淡雅档取值 | 作用 |
| --- | --- | --- |
| `--g-blur` | `10px` | 模糊半径，越大越"厚" |
| `--g-sat` | `170%` | 饱和度，让透出来的颜色更透亮 |
| `--g-alpha` | `.68` | 面板白度，越大越实、越小越透 |
| `--g-edge` | `rgba(255,255,255,.5)` | 边缘亮线 |

> 需求方看过「淡雅 / 标准 / 浓烈」三档对比预览后选了**淡雅**，即上表的值。

**兜底**：不支持 `backdrop-filter` 的老浏览器（老安卓等）自动退回**不透明白底**，形状、颜色、可读性都保住，只是没有玻璃感（见样式表 `@supports not` 那段）。

字体：系统默认中文字体（Windows 用微软雅黑），字号 14px 起，标题 18~20px。

## 二、总体布局

### 桌面（宽屏）

```
┌────────────┬───────────────────────────────────────────────┐
│  课表      │  第 2 学期            第 7 周        [编辑课程] │
│            │                                               │
│  设置      │                                               │
│            │              课程方块区域                      │
│            │                                               │
│            │                                               │
│  [收起 ◀]  │                                               │
└────────────┴───────────────────────────────────────────────┘
   约 1/5                    内容区
```

- 左侧菜单栏：**约 1/5 宽**（最小 200px，最大 260px），**可以隐藏**
  - 玻璃风格下它是一块**独立的圆角玻璃板**（不再是从上到下的白条），页面四周和各块之间留 16px 缝，缝里透出彩色底
- 隐藏后内容区自动占满，菜单栏边缘留一个**细的展开按钮**（◀ / ▶）把它拉回来
- 菜单项只有两项，靠上排列：**课表**（最上方）、**设置**
- 「设置」是**二级菜单**：展开后是 **学期** 和 **提醒** 两项，点谁就打开谁（默认展开、选中态用浅蓝底）

### 手机 / 平板（窄屏）

- 菜单栏**默认收起**
- 顶部左侧一个 **☰ 按钮**，点击后菜单栏**从左侧滑出**，盖在内容上，背后加半透明遮罩
- 点遮罩或点菜单项后自动收起

### 断点

| 宽度 | 布局 |
| --- | --- |
| ≥ 1024px | 桌面：左菜单常驻 + 右内容 |
| 768 ~ 1024px | 平板：同上但菜单更窄，或默认收起 |
| < 768px | 手机：菜单变抽屉、默认收起；课表 **7 列压缩变瘦** |

## 三、通用组件

### 3.1 按钮（四种）

| 名称 | 样式 | 用在哪 |
| --- | --- | --- |
| 主按钮 | 蓝底白字（`#2F6FED`），圆角 10px | 添加学期、添加课程、添加提醒、前往设置 |
| 描边按钮（设置） | **玻璃白底 + 蓝字 + 蓝边框** | 学期卡片 / 课程卡片上的「设置」 |
| 危险按钮（删除） | **玻璃白底 + 红字 + 红边框** | 学期卡片 / 课程卡片上的「删除」 |
| 文字按钮 | 蓝字 + 下划线，无边框 | 学期卡片上的「设为默认」 |

> **已确认（2026-10-15）**：设置按钮用的是 **白底 + 蓝字 + 蓝边框**（描边按钮）。
> **2026-10-16 起**：四种按钮的"白底"都改成**半透明玻璃底**，圆角 10px。

### 3.2 卡片

**半透明玻璃板**：底色 `rgba(255,255,255,.68)`、圆角 16px、1px 白色亮边、顶部一道内高光、
下面一层很淡的投影（`0 10px 30px rgba(31,60,130,.06)`）。背后透出页面底色。

### 3.3 弹窗

居中、**半透明遮罩（带模糊）**、右上角 ✕、点遮罩可关闭。弹窗本身也是玻璃板。
删除类操作**必须先弹确认框**（「确定删除……吗」），确认了才真删。

### 3.4 空态

内容区正中：一行灰字 + 一个主按钮（如课表页的「你还没有设置默认学期」+「前往设置」）。

## 四、各页面设计

### 4.1 课表页（默认页）

**有默认学期时：**

```
┌──────────────────────────────────────────────────────────┐
│ 第 1 学期            第 7 周                    [编辑课程] │
├──────────────────────────────────────────────────────────┤
│       周一   周二   周三   周四   周五   周六   周日  │
│        ┌─────┐                ┌─────┐                    │
│        │ 高数 │                │ 英语 │                    │
│        │     │                └─────┘                    │
│        └─────┘                                            │
│                 ┌─────┐                                   │
│                 │ C语言│                                   │
│                 └─────┘                                   │
└──────────────────────────────────────────────────────────┘
```

- 顶部一行三处信息：**左上**「第 x 学期」、**中间**「第 x 周」、**右上**「编辑课程」按钮
- 主体是按时间横排的网格：
  - **纵向（y）是时间**，从上到下时间递增（这就是「第四象限」的观感：y 向下为正）
  - **横向（x）是周几**，从左到右
  - **不画坐标轴线**（不画箭头和格子框）；**y 轴不写时间刻度**，**x 轴下方写周几（周一 ~ 周日，7 列）**
- 课程画成**小方块**（玻璃质感）：**半透明**地透出课程颜色 + 方块内显示课程名
  - **不是全透明**：颜色要看得出来、形状也要看得出来（`--b-alpha: .72`，另加一圈亮边，浅色也认得出形状）
  - 方块颜色 = **用户给这门课自己选的颜色**（课程编辑弹窗里的「颜色」），玻璃效果跟着这个颜色走
  - 方块高度按**真实时间比例**（比如上 100 分钟，方块就是 100 分钟那么高）
  - 方块宽度 = 该列宽度
- **整块课表装在一整块玻璃板里**（2026-10-16 需求方拍板「装进玻璃板」）；顶部那行「第 x 学期 / 第 x 周 / 编辑课程」也是一块玻璃条
- 页面**不可拖动、不可缩放**（禁用双指缩放和拖动）
- **点方块** → 弹窗显示：课程名字、任课老师、上下课时间、上课地点

**没有默认学期时：**

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                                                          │
│                你还没有设置默认学期                       │
│                    [ 前往设置 ]                           │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**已确认（2026-10-15）**
- y 轴**不标时间刻度**（不写 8:00 / 10:00 这类文字）
- x 轴**标周几**，画 **7 列**（周一 ~ 周日）
- 手机竖屏：**压缩**显示，7 列一起变瘦，方块里的课程名适当缩短
- 方块里的字：浅色方块上用深色字，深色方块上用白字（按颜色亮度自动选）；方块是半透明的，字底下再叠一层很淡的影避免发飘
- **方块是玻璃的**：半透明、有光泽，但颜色和形状都要看得出来（2026-10-16 需求方确认）
- **课表装进玻璃板**：2026-10-16 需求方在「浮在背景上 / 装进玻璃板」两个预览里选了**装进玻璃板**

### 4.2 设置 → 学期

```
┌──────────────────────────────────────────────────────────┐
│  设置                                                     │
│  设置 ▸ 学期                                              │
├──────────────────────────────────────────────────────────┤
│                                     [+ 添加学期]          │
│  ┌────────────────────────────────────────────────────┐  │
│  │  第 1 学期   2026/09/01 - 2027/01/15               │  │
│  │              [设置]  [删除]   设为默认               │  │
│  └────────────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────────────┐  │
│  │  第 2 学期   2027/02/20 - 2027/07/10               │  │
│  │              [设置]  [删除]   设为默认               │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

- 每个学期一张长方形卡片：左边学期序号 + 起止日期，右边三个操作
- 「设为默认」：蓝色下划线文字按钮，无边框；已是默认的显示成「默认学期」并置灰不可点
- 「添加学期」弹出表单：学期序号 + 起始日期 + 结束日期（日期选 `yyyy/mm/dd`）
- 创建完立即出现在列表里

### 4.3 课程设置页

- **左侧菜单栏没有任何一项被点亮**（因为这一页不属于菜单里任何一页）
- 顶部：该学期的**序号 + 起止日期**，可直接修改
- 中间：课程列表（卡片），底部/右上「添加课程」按钮
- 课程卡片宽度 = **内容区的 8 分之 7**（居中偏左），结构：

```
┌────────────────────────────────────────────────────┐
│ ●  高等数学   张老师                               │
│    周一 周三   2026/09/01 - 2027/01/15             │
│    08:00 - 09:40   3 号教学楼 201                  │
│    备注：带计算器                          [设置][删除] │
└────────────────────────────────────────────────────┘
   ↑ 左侧有色圆 = 课程颜色
```

- 冲突的课程卡片：**边框和提示文字变红**，并显示一行「⚠ 与《XXX》时间冲突，请修改」

### 4.4 设置 → 提醒

```
┌──────────────────────────────────────────────────────────┐
│  设置                                                     │
│  设置 ▸ 提醒                                              │
├──────────────────────────────────────────────────────────┤
│                                     [+ 添加提醒]          │
│  ┌────────────────────────────────────────────────────┐  │
│  │ [开] 每一节课上课  [00]:[30] [前] 下一节课          │  │
│  │      附加信息：名称 地点                     [删除] │  │
│  └────────────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────────────┐  │
│  │ [开] 新的一天到来  [06]:[00] [后] 今天的所有课      │  │
│  │      附加信息：上课时间 名称                 [删除] │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

- 一条提醒**一行**，从左到右：开关、事件下拉、时、分、前/后、范围下拉、附加信息（多选标签）、删除
- 手机上这一行会折成几行显示
- 添加提醒也是弹窗表单，字段同上面

## 五、交互细节

- 所有「创建完成后立即显示」的地方：弹窗提交后关闭，列表当场刷新，不刷新整页
- 桌面 hover：卡片阴影加深；**课程方块轻微上浮 + 阴影加深**；按钮背景变化（玻璃风格下不再用变暗滤镜）
- 点方块 / 点卡片 → 弹窗
- 冲突课程：课程设置页标红；**课表页直接不画**
- 删除学期 / 课程：**先弹确认框**，确认后才删
- 同一时刻命中多条提醒：**合并成一条**通知，不连弹
